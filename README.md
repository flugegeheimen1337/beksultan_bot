# Личный финансовый учёт

Telegram-бот: доходы, расходы, Excel-отчёты и книга должников.

Книга должников живёт отдельно от операций и попадает в отчёт второй вкладкой `Должники`.

## Команды

- `/start` — меню
- `/report` — отчёт
- `/debts` — книга должников
- `/cancel` — отменить текущий шаг
- `/help` — подсказка

Кнопки: `+ Доход`, `− Расход`, `📊 Отчёт`, `📒 Должники`.

Отчёт можно собрать за день, за период или за всё время. В меню отчёта включается автоотчёт: каждый день в заданный час бот присылает итог, если за день были операции.

## Запуск

```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env
venv/bin/python -m bot
```

Переменные:

| Переменная | Смысл |
| --- | --- |
| `BOT_TOKEN` | токен BotFather |
| `TIMEZONE` | часовой пояс «сегодня» и «вчера», по умолчанию `Asia/Dubai` |
| `AUTO_REPORT_HOUR` | час автоотчёта, 0–23 |
| `DB_PATH` | файл SQLite |

В группе бот видит суммы и кнопки, если он администратор. Иначе в @BotFather отключите Privacy Mode (`/setprivacy`) и добавьте бота в группу заново.

На сервере бот ставится как systemd-сервис `finance-bot` скриптом `deploy/install.sh`. Перед запуском положите `.env` в `/opt/finance-bot`. База лежит в `/opt/finance-bot/data` — её стоит копировать вместе с бэкапами.
